As a personal hobby of mine, I like to recreate some of my favorite logos using RealWorld Paint. In some cases, I have used them to make some personalized clothing, labels, stickers, and cosplay items (Non-commercially of course). Since I know it can take forever to make certain logos accurately for these purposes (and I don't like the thought of these files simply collecting dust on my computer), all of these images here are in an SVG/Vector Format to save you some time.

Please note that images with a ~CYAN BACKGROUND~ have download links embeded with the original .rli (RealWorld Layered Image Files) files because some of the .svg files do not display correctly on a website. To view/edit these specific files, Click on the image to download the file and open them with RealWorld Paint. The program just mentioned does support saving these files as an .svg, so if you wish to take these files into another program you are more comfortable with, it is 100% possible to do so. Just be warry that some effects, such as object outlines and gradients, behave differently when brought into other alternate programs.
